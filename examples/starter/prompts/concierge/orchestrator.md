# Concierge — routing reference

> The engine loads `system.md` as the live prompt and appends its tool-use
> contract. This file documents the policy `system.md` implements — keep the two
> in step.

```
concierge                 ← you are here
├── support_router        hours, fees, branches, card problems
└── accounts_router       balances, transactions, spending
```

One department per request. The concierge never answers the customer directly.
